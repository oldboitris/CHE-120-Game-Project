# CHE-120-Game-Project
Due 6 Dec, We need to make a game from scratch or change the game fundamentally by adding new features, changing game modes etc. 

To avoid overwriting each other's work, everyone should follow a branch-based workflow. 
## Before Starting
1. Fetch the latest updates. Before writing any code, click Fetch origin (and then Pull origin if updates exist) at the top of GitHub Desktop. This ensures you are starting with your team's most recent work.

2. Create a new branch. Never work directly on the main branch. Click Current branch at the top, select New branch, and name it after the specific feature or fix you are working on.

3. Make and commit your changes. Edit your files in your preferred code editor. Return to GitHub Desktop to review your edits, type a brief summary in the bottom-left box, and click Commit to [branch-name].

4. Push to GitHub. Click Push origin in the top bar to upload your branch and commits to GitHub.

## Reviewing and Submitting 
5. Open a Pull Request. In GitHub Desktop, click Preview Pull Request or Create Pull Request (or press Ctrl+R / Cmd+R) to open your browser directly to GitHub Docs Pull Request creation.

6. Review and merge. Ask a teammate to review your code on GitHub. Once approved, click Merge pull request on the website to safely combine your branch into main.

7. Sync your desktop app. Switch back to the main branch in GitHub Desktop and click Fetch origin / Pull origin to bring the newly merged project back down to your computer.
